# Baby Blue

主色 `#89CFF0`，共 50 个 256×256 透明 PNG。

这套只换了颜色，图形和大小与[柔和蓝原版](../IconSet/)相同。地区图标保留白字，PayPal 保留双 P 的深浅层次。

![Baby Blue 图标，浅色和深色背景](Preview/all-icons.png)

## 文件

- `IconSet/`：50 个图标，文件名与原版一致。
- `Preview/`：全套预览图。
- `icon-links.txt`：图标链接。
- `group-icon-links.json`：策略组与图标的对应关系。
