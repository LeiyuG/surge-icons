# Baby Blue 图标

独立的 Baby Blue A 配色套装，主色 **`#89CFF0`**，共 **50 个 256×256 透明 PNG**。

沿用原版已调整好的图形、字形、大小、位置与透明背景，仅更换配色。地区字母底牌改为 Baby Blue，保留白字；PayPal 保留同色系深浅分层。

![全套深浅背景预览](Preview/all-icons.png)

## 文件

- `IconSet/`：完整 50 个 PNG，文件名与原版一致。
- `Preview/all-icons.png`：由本套实际 PNG 生成的深浅背景预览。
- `icon-links.txt`：本套全部图标的独立直链。
- `group-icon-links.json`：本套策略组与图标对应关系。

原版保留在仓库根目录的 `IconSet/`。本套全部文件位于 `BabyBlue/`，不覆盖原版。
